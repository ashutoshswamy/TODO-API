# Flask TODO API

A simple RESTful API built with Flask for managing todo items. Provides basic CRUD operations for todo tasks.

## Features

- Create new todo items
- Retrieve all todos
- Retrieve a specific todo by ID
- Update existing todos
- Delete todos
